# תנועות ההצבעה

קבצים שהוקלטו ב-Bus Servo Control V3.5 ונשמרו על בקר המנועים של הרובוט.
כל תנועה מתחילה ומסתיימת בתנוחת עמידה, וכך אפשר להריץ כל תנועה אחרי כל תנועה.

| קובץ | מקום | משבצת על הרובוט | משך | מנועים שזזים |
|---|---|---|---|---|
| Point_Toilet.rob | שירותים | 124 | 3.1 שניות | 7 (זרוע שמאל הצידה) |
| Point_Heder_Eyoon.rob | חדר עיון | 125 | 3.0 שניות | 14, 15, 16 (מרפק וזרוע ימין) |
| Point_Elevator.rob | מעליות | 126 | 3.0 שניות | 8, 16 (שתי הזרועות למעלה) |
| Point_Segel.rob | חדר סגל | 127 | 3.0 שניות | 7, 8 (זרוע שמאל) |

מבנה כל תנועה: עמידה (0.3 שניות) ← הרמת היד (0.6–0.7) ← החזקה (1–1.2) ← חזרה לעמידה (1).

ערכי העמידה (מ-`No.0 Attention.rob`), מנועים 1–16:
`500, 387, 500, 593, 500, 575, 800, 724, 500, 612, 500, 406, 500, 425, 200, 275`

**הצבה:** התנועות מכוונות למקומות כשהרובוט עומד בנקודה הקבועה ופונה לכיוון הקבוע. אם מזיזים את הרובוט, ההצבעות לא יתאימו.

**שחזור:** אם התנועות נמחקו מהרובוט, פותחים כל קובץ ב-Bus Servo Control (Open action file),
בוחרים את מספר המשבצת ב-Action group, ולוחצים Download.

**פירוט פריים-אחרי-פריים:** `python scripts/show_motion.py firmware/motions/*.rob`
