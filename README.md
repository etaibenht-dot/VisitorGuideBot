# VisitorGuideBot – הרובוט המדריך ליום הפתוח

רובוט Hiwonder TonyBot שמזהה מבקר, מנפנף, עונה על שאלות בעברית ומצביע למקומות בבניין.
אנשי הסגל מעדכנים את המידע שהרובוט משתמש בו דרך אתר ניהול, בלי לגעת בקוד.

## מה יש בפרויקט

| תיקייה / קובץ | מה זה |
|---|---|
| `admin/` | אתר הניהול לסגל (FastAPI + Jinja2) |
| `robot/` | קוד הרובוט: שיחה, זיהוי פנים, תנועות |
| `db.py` | כל הגישה למסד הנתונים, משותף לאתר ולרובוט |
| `data/guide.db` | מסד הנתונים (SQLite). נוצר בהתקנה, **לא** נשמר ב-Git |
| `scripts/` | `init_db.py` (יצירת המסד), `create_user.py` (יצירת משתמש) |
| `firmware/` | הקוד שצרוב על בקר ה-ESP32 של הרובוט |
| `tests/` | בדיקות אוטומטיות (`pytest`) |

## התקנה במחשב ה-Windows של הרובוט (פעם אחת)

1. מתקינים **Python 3.12** מ-python.org. בהתקנה מסמנים **Add Python to PATH**.
2. מעתיקים את תיקיית הפרויקט למחשב.
3. לחיצה כפולה על **`install_windows.bat`**. הוא:
   - יוצר סביבת Python ומתקין את כל הספריות
   - יוצר את הקובץ `.env` ואת מסד הנתונים
   - מבקש שם משתמש וסיסמה למשתמש הסגל הראשון
4. פותחים את הקובץ **`.env`** ב-Notepad וממלאים:
   - `GEMINI_API_KEY` – המפתח של Gemini
   - `ROBOT_COM_PORT` – הפורט של הרובוט (בודקים ב-Device Manager, תחת Ports, למשל `COM3`)
   - `SESSION_SECRET` – טקסט אקראי ארוך כלשהו

## הפעלה

| מה | איך |
|---|---|
| אתר הניהול | לחיצה כפולה על **`start_admin.bat`**. הדפדפן ייפתח בכתובת `http://localhost:8000` |
| הרובוט | לחיצה כפולה על **`start_robot.bat`** |

אפשר להריץ את שניהם במקביל. שינוי שנשמר באתר משפיע כבר על השאלה הבאה שהרובוט מקבל.

אתר הניהול נפתח רק ממחשב הרובוט עצמו. כדי לפתוח אותו ממחשב אחר באותה רשת, משנים ב-`start_admin.bat` את `127.0.0.1` ל-`0.0.0.0`.

**לפני הפעלת הרובוט:** לסגור את Bus Servo Control ואת ה-Serial Monitor של Arduino, כי הם תופסים את הפורט.
כדי לכבות את הרובוט: ESC על חלון המצלמה.

## איך הרובוט עונה

1. מבקר שואל שאלה, והדיבור מתומלל לטקסט.
2. הרובוט קורא מהמסד: מקומות פעילים, מאגר הידע, ואירועים של היום שעוד לא הסתיימו.
3. Gemini מנסח תשובה **רק** מהמידע הזה, ומתחיל אותה בתגית:
   - `[PLACE:<מספר>]` – התשובה מכוונת למקום. אם למקום יש תנועה, הרובוט מצביע אליו בזמן שהוא מדבר.
   - `[UNKNOWN]` – אין מידע. הרובוט מפנה למזכירות, והשאלה נשמרת בעמוד "שאלות שלא נענו".
   - `[NONE]` – תשובה רגילה, בלי תנועה.
4. נפנוף (תנועה 9) כשמבקר מזוהה, השתחוות (תנועה 10) כשאומרים "תודה".

## תנועות הרובוט

התנועות מוקלטות ב-Bus Servo Control ושמורות על הרובוט:

| מספר | תנועה |
|---|---|
| 0 | עמידה |
| 9 | נפנוף |
| 10 | השתחוות |
| 124 | הצבעה לשירותים |
| 125 | הצבעה לחדר עיון |
| 126 | הצבעה למעליות |
| 127 | הצבעה לחדר סגל |

**הוספת תנועה חדשה:** מקליטים ושומרים אותה על הרובוט, ומוסיפים את המספר שלה בשלושה מקומות:
`ALLOWED_GROUPS` ב-`firmware/tonybot_listener/tonybot_listener.ino` (ולצרוב מחדש),
`ALLOWED_GROUPS` ב-`robot/robot_motion.py`, וטבלת `gestures` במסד (ב-`db.py`, ברשימה `SEED_GESTURES`, ואז להריץ את `scripts\init_db.py`).

## פיתוח ב-Mac

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python scripts/init_db.py && python scripts/create_user.py
uvicorn admin.main:app --reload --port 8000     # אתר הניהול
python -m robot.academy_guide                   # הרובוט
python -m pytest                                # בדיקות
```

ב-Mac הפורט של הרובוט נראה כמו `/dev/cu.usbserial-XXXX`. אם PyAudio לא מותקן: `brew install portaudio` ואז שוב `pip install PyAudio`.

## גיבוי

כל המידע שהסגל הכניס נמצא בקובץ אחד: `data/guide.db`. כדי לגבות, מעתיקים אותו כשהרובוט ואתר הניהול כבויים.
